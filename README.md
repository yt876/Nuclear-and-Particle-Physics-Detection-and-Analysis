# 核与粒子物理实验探测与分析

👉 在线课程网站：https://yt876.github.io/Nuclear-and-Particle-Physics-Detection-and-Analysis/

北京航空航天大学《核与粒子物理实验探测与分析》课程网站源码（Jekyll + GitHub Pages）。

## 目录结构

- `index.md` — 课程主页（课程概述、师资团队、课程大纲等）
- `Syllabus.md` — 课程安排；`coursework.md` — 课程作业；`experiment.md` — 课程实验
- `programming.md` — ROOT 入门；`montecarlo.md` — 蒙卡模拟；`tools.md` — 软件工具
- `reference.md` — 学习资料；`knowledge.md` — 学科知识库；`faq.md` — 常见问题；`discussion.md` — 讨论留言
- `_layouts/default.html` — 全站布局；`assets/css/style.scss` — 全站样式
- `assets/data/knowledge.json` — 学科知识库数据；`assets/katex/` — 公式渲染依赖
